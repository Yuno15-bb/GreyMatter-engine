#     gardening pass dirties the engine
#         → update.sh refuses to update a dirty engine
#         → the user silently falls behind, version after version
#
# The list lived inline in install.sh only. It is now read from here by
# install.sh, cbrain/update.sh and hooks/brain_doctor.py — one definition, three
# consumers. A list copied into three files diverges; this repo learned that the
# hard way the same day, with two recall engines that disagreed on 65 documents.
#

# parser. One directory per line, `#` comments and blank lines ignored.
